# Yam shopping — מרכז הצוות (תוסף כרום)

התוסף מקפיץ התראה וחלון על המסך (שנשאר עד שמאשרים או סוגרים) על כל מה שקורה באתר: משתמשים חדשים, הערות ופניות, תקלות באתר, מתכונים, לימודי בוט, חנויות וסניפים, דיווחי מחיר, מבצעים ודברי תורה.

## מה חדש בגרסה 2.0 (2.0.1)
- עיצוב 2.0 כמו באתר: לוגו Yam על כחול כהה, ורוד ושמנת, פינות מעוגלות.
- 2.0.1: הוצאו קבצי הגופן מהתוסף, כי הסינון (נטפרי) חסם את ה-zip בגללם ("דחוס מדי").
- אייקונים בקו אחיד במקום אימוג'י, בכל המסכים ובהתראות. מצב כהה אוטומטי לפי המחשב.
- קוד מסודר: רכיבי התצוגה המשותפים (כרטיס עדכון, כפתורי אישור/דחייה, אייקונים) בקובץ אחד `ui.js`.
- הרשאות מצומצמות יותר: גישה לאתר רק לתיקיית `/ext/` (בדיקת גרסה), במקום לכל האתר.

## הרשאות ופרטיות
| הרשאה | למה |
|---|---|
| `storage` | שמירת הכניסה, ההגדרות והעדכונים האחרונים במחשב בלבד |
| `alarms` | בדיקה קבועה (כל דקה כברירת מחדל) מה חדש באתר |
| `notifications` | הודעה קופצת במחשב |
| `ygyfodxfbebnkwdcbjrp.supabase.co` | השרת של האתר: כניסה, עדכונים ואישורים |
| `www.yamshopping.com/ext/*` | רק בדיקה אם יש גרסה חדשה לתוסף |

התוסף לא קורא דפים, לא רואה היסטוריית גלישה ולא אוסף מידע מהמחשב. אין בו קוד מרוחק ואין ספריות מבחוץ. פרטי משתמשים שמופיעים בהתראות מוצגים רק לצוות, לפי ההרשאה בשרת, ונמחקים מהמחשב ביציאה מהתוסף.

## איך זה עובד
- **כניסה עם המייל והקוד של האתר** — אותו חשבון.
- **רק צוות ומנהלים** יכולים להיכנס. משתמש רגיל מקבל "התוסף פתוח רק לצוות".
- **כל אחד רואה רק מה שמותר לו:** בעלים ומנהל רואים הכל. צוות פיקוח רואה רק את מה שהוא מאשר (מתכונים, לימודי בוט, חנויות, מחירים, מבצעים, דברי תורה) — **לא** משתמשים ולא הערות. זה נאכף בשרת, לא רק בתוסף.
- אם מורידים מישהו מהצוות — התוסף שלו מתנתק לבד בבדיקה הבאה.
- המספר על האייקון = כמה דברים ממתינים עכשיו לאישור. לחיצה על התראה פותחת את הבק אופיס בדיוק בלשונית הנכונה.
- הגדרות: על מה להתריע, "רק מה שממתין לאישור", כל כמה זמן לבדוק, וכתובת האתר (אם האתר עובר כתובת).

## אישור ודחייה ישר מהתוסף (מגרסה 1.7.0)
- בחלון התוסף יש רשימה **"לאישור עכשיו"** — חנויות, סניפים, מחירים, מתכונים, לימודי בוט, מבצעים, דברי תורה וחוות דעת — עם כפתורי **אישור** ו-**דחייה**. גם בחלון שקופץ על המסך.
- דחייה/מחיקה — רק בלחיצה שנייה ("בטוח? לחצו שוב").
- מחיר שדווח כלא נכון: **המחיר נכון** (מנקה את הדיווחים) או **המחיר לא נכון** (מוחק אותו).
- הודעות, פניות ושפה לא נקייה (רק למנהלים): **טופל**.
- הפעולה עצמה נעשית בשרת (`staff_decide`) ונבדקת שם לפי התפקיד — צוות פיקוח לא יכול לטפל בהודעות ובפניות.
- דרוש: להריץ שוב את קוד ה-SQL של האתר (בק אופיס ← הגדרה ראשונית ← שלב 1).

## תקלות באתר (מגרסה 1.8.0)
- כל שגיאה חדשה ביומן השגיאות של האתר קופצת כהתראה — רק לבעלים ולמנהלים.
- בהתראה: מה השגיאה, איפה בקוד, גרסת האתר ומי נתקל בה. לחיצה פותחת את הבק אופיס ← יומן שגיאות.
- **טופל** — מוחק את השגיאה מהיומן. אפשר לכבות ב-הגדרות ← "תקלה באתר".
- דרוש: להריץ שוב את קוד ה-SQL של האתר.

## חיפוש מוצרים ומחירים (מגרסה 1.12.0)
- כפתור **החיפוש** למעלה (או "חיפוש" במסך הראשי) ← כותבים שם מוצר או ברקוד.
- **מחירים:** כל המחירים שיש באתר על המוצר — מכל הרשתות והסניפים, מהזול ליקר. לכל חנות רק המחיר האחרון שלה. רואים גם מה שממתין לאישור, מבצעים, מחירים מ"שקיפות מחירים", ומחירים שדווחו כלא נכונים. ⏳ = לא עודכן 30 יום.
- **מוצרים בקטלוג:** המוצרים שבקטלוג של האתר (שם, מותג, קטגוריה, ברקוד). לחיצה ← המחירים של המוצר.
- אפשר כמה מילים: "חלב תנובה" ימצא גם "חלב תנובה 3% 1 ליטר".
- "פתיחה באתר" פותח את חיפוש המחירים באתר על אותו מוצר.
- קריאה בלבד, ישר מהשרת של האתר. לא צריך להריץ קוד SQL חדש.

## עדכונים
- התוסף בודק לבד (פעם ב-6 שעות) אם יש גרסה חדשה, ומודיע עם קישור להורדה: https://www.yamshopping.com/ext/yam-staff-extension.zip
- עדכון אוטומטי לגמרי (בלי להוריד ולהחליף) — רק כשהתוסף נמצא בחנות של כרום (Chrome Web Store, אפשר כ"לא רשום" — רק מי שיש לו קישור רואה).

## התקנה (פעם אחת, 2 דקות)
> לפני כן: להריץ שוב את קוד ה-SQL באתר (בק אופיס ← הגדרה ראשונית ← העתקה ← Supabase ← SQL Editor ← Run). נוספו שם הפונקציות של התוסף.

1. מחלצים את `yam-staff-extension.zip` לתיקייה קבועה במחשב (למשל `מסמכים\YAM-תוסף`) — **לא למחוק אותה אחר כך**, כרום טוען את התוסף ממנה.
2. בכרום כותבים בשורת הכתובת: `chrome://extensions` ← Enter.
3. מדליקים למעלה משמאל **Developer mode** (מצב מפתח).
4. לוחצים **Load unpacked** (טעינת תוסף לא ארוז) ← בוחרים את התיקייה שחילצתם (זו שבתוכה `manifest.json`).
5. לוחצים על סמל התוספים (חתיכת פאזל) ליד שורת הכתובת ← נעיצה של "Yam shopping — מרכז הצוות".
6. לוחצים על האייקון ← מייל + קוד ← **כניסה**.

**לאנשי צוות נוספים:** שולחים להם את אותו ZIP, והם עושים אותם שלבים עם המייל והקוד **שלהם**. קודם מוסיפים אותם כצוות בבק אופיס ← צוות.

**עדכון גרסה:** מחליפים את הקבצים בתיקייה ← `chrome://extensions` ← על התוסף.

**נטפרי:** התוסף מתחבר רק לשרת של Supabase (`ygyfodxfbebnkwdcbjrp.supabase.co`) — אותו שרת שהאתר כבר משתמש בו.
**Windows:** כדי שיופיעו התראות — הגדרות ← מערכת ← הודעות ← לוודא ש-Google Chrome מופעל.
