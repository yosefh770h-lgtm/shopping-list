# 📲 אפליקציית אנדרואיד

"חלון משופר" שפותח את האתר החי (https://yamshopping.com). **כל עדכון באתר מגיע מיד גם לאפליקציה**, ולא צריך להוציא גרסה חדשה. גרסה חדשה צריך רק כשמשנים את הקוד בתיקייה הזו.

עובדת גם בטלפון בלי כרום (טלפונים מסוננים), כי היא משתמשת ברכיב התצוגה של אנדרואיד עצמו.

## מה היא מוסיפה על דפדפן רגיל
- 📷 מצלמה לסריקת ברקוד, ו-📍 מיקום ל"קרוב אליי". שתי ההרשאות ניתנות רק לאתר שלנו, ונשאלות בפעם הראשונה שצריך אותן
- 💾 הורדות מהאתר (גיבוי, CSV) נשמרות בתיקיית ההורדות של הטלפון
- 🔗 קישורים לוויז, וואטסאפ, מייל, טלפון ואתרים אחרים נפתחים באפליקציות שלהם
- 🖼️ בחירת קבצים ותמונות (קבלה, תמונת מתכון, קובץ מחירים)
- 🛡️ עובדת ברשת נטפרי גם בטלפון שאין בו את תעודת האבטחה של נטפרי: תעודות נטפרי (NetFree Root CA X2) מגיעות בתוך האפליקציה (`res/raw`, `res/xml/network_security_config.xml`)
- 📡 מסך "אין אינטרנט" עם "נסו שוב", וכפתור "חזרה" שחוזר אחורה באתר
- 🔄 **עדכון מתוך האפליקציה** (מגרסה 1.3): כשיוצאת גרסה חדשה מופיע "יש גרסה חדשה · לעדכן". לוחצים, האפליקציה מורידה את `download/yamshopping.apk` מהאתר שלנו ומתקינה במקום הישנה, ואנדרואיד מבקש אישור "עדכון" (בפעם הראשונה גם "לאפשר ממקור זה"). הרשימות והחשבון נשארים. אחרי העדכון הראשון מתוך האפליקציה, אנדרואיד 12 ומעלה יכול לעדכן גם בלי לשאול (`Updater.java`)
- 🔔 **התראות בטלפון** (מגרסה 1.3): התראות הפעמון שבאתר (הוזלות, מבצעים, ערב שבת) עוברות להתראות של הטלפון. בדיקה ברקע כל כ-3 שעות, גם כשהאפליקציה סגורה ובלי חשבון: גרסה חדשה, "מה חדש באתר" (מהבק אופיס ← 📢 פרסום עדכון, דרך `updates_public`), ותזכורת ביום שישי בבוקר. לא בלילה (22:00–07:00) ולא בשבת (`CheckJob.java`, `Notifier.java`)
- 💬 **הודעות מהצוות כהתראת שיחה** (מגרסה 1.8): כשעונים למשתמש בצ'אט, ההודעה קופצת אצלו בטלפון גם כשהאפליקציה סגורה (בדיקה כל רבע שעה), תחת "שיחות", עם "השב" ו"סימון כנקרא" ומספר על האייקון. הטלפון מזוהה במזהה סודי אקראי שהאתר מצמיד לחשבון אחרי הכניסה ומנתק ביציאה (`Inbox.java`, `ActionReceiver.java`, ובשרת `app_device_register` / `app_inbox` / `app_inbox_reply`)
- ✨ **שינויים באתר מגיעים לבד**: כשחוזרים לאפליקציה והאתר התעדכן בינתיים, היא נטענת מחדש לבד (לא באמצע הקלדה), עם ההודעה "האפליקציה עודכנה"

- 🧳 **נפתחת גם בלי אינטרנט מהפעם הראשונה** (מגרסה 2.1): עותק של האתר נארז בתוך ה-APK (`build.sh` מעתיק מ-`shopping-list-site` ל-`assets/site`). הוא נטען רק כשהדף הראשי לא נטען בכלל (אין אינטרנט ואין עותק שמור של ה-Service Worker, או שגיאת 5xx מהשרת), באותה כתובת www.yamshopping.com — כך הרשימות שבטלפון מופיעות. כשהקליטה חוזרת חוזרים לאתר החי (`Offline.java`)
- 🔋 **התראות גם כשהאפליקציה סגורה בטלפונים עם חיסכון סוללה חזק** (מגרסה 2.1): בכרטיס "התראות בטלפון" באתר — "לאשר פעילות ברקע" (חלון המערכת לפטור מאופטימיזציית סוללה, רק בלחיצה של המשתמש), ובשיאומי גם כפתור שפותח את "הפעלה אוטומטית" (`Power.java`, `YamApp.askBattery()` / `YamApp.openAutostart()`)
- 🎬 **אנימציית הפתיחה היא של האתר** (מגרסה 2.1): האפליקציה מראה רק כחול (#1e3a5f) עד שהדף מצויר, והאתר מנגן את #yi2. כשחוזרים לאפליקציה אחרי 30 דקות ברקע היא מבקשת אותה שוב (`yamSplashAgain()` ב-index.html)
- 📡 **סנכרון בבלוטות' עם "רשימת קניות אופליין"** (מגרסה 2.2): קוד של 4 ספרות, וסנכרון חי כל עוד הטלפונים קרובים (`Bt.java`, גשרים `btListen/btJoin/btConnect/btSend`). את האפליקציה האופליין בונים ב-`./build.sh offline` (בלי הרשאת אינטרנט)
- 🔋 **בדיקה ברקע עמידה יותר ובכל שעות היממה, רק לא בשבת** (מגרסה 2.2): `Wake.java` גיבוי ל-`CheckJob`, ו-`Power` מזהה `blocked` / `batLost`
- 🧾 **קבלה של אושר עד מהטלפון** (מגרסה 2.2): `YamApp.receiptJson`, רק לכתובות `*.pairzon.com`
- 🐞 **דיווח קריסות** (מגרסה 2.2): `Crash.java` שומר, והאתר שולח ליומן התקלות בפתיחה הבאה (`YamApp.lastCrash`)

## מה לא עובד בתוך האפליקציה
- כניסה עם גוגל: גוגל חוסמת אותה בחלון של אפליקציה. האתר מזהה את האפליקציה (`YamShoppingApp/` בדפדפן) ומסביר להיכנס עם מייל וקוד
- Web Push עצמו לא עובד בתוך האפליקציה. במקומו (מנובמבר 2026, בלי גרסה חדשה, מ-1.9 ומעלה): כל התראה שהשרת שולח לחשבון (מבצעים, מתכונים, תשובות מחנויות, תזכורות, התראות צוות) מסומנת בשרת "נשלחה" גם כשיש לחשבון רק טלפון עם האפליקציה, והאפליקציה מושכת אותה בבדיקה ברקע (כל רבע שעה) יחד עם ההודעות מהבק אופיס (`app_notices_for` + `app_push_hits`). הודעות צ'אט מגיעות כמו קודם דרך `app_inbox`.
- הקלטה קולית שנשענת על זיהוי הדיבור של כרום

## בנייה
```
KEYSTORE=/path/yamshopping-signing-key.p12 KEYSTORE_PASSWORD=... ./build.sh
```
צריך Java 17+, Python 3 ו-curl. הכלים יורדים פעם אחת לתיקייה `.tools` ונבדקים לפי טביעת אצבע. הפלט: `dist/yamshopping-<גרסה>.apk`.

לגרסה חדשה: מעלים ב-`AndroidManifest.xml` את `versionCode` (מספר שלם, תמיד גדל) ואת `versionName`.

### בכל גרסה חדשה
1. מעלים ב-`AndroidManifest.xml` את `versionCode` ו-`versionName`, וב-`AppActivity.java` את `UA_MARK`.
2. בונים, ומחליפים את `shopping-list-site/download/yamshopping.apk`.
3. מעדכנים את `shopping-list-site/download/app-version.json`: גרסה, תאריך ו"מה חדש" (שורה לכל חידוש).

מזה הכל קורה לבד: בחלון ההורדה באתר כתוב "עודכן לגרסה" ו"מה חדש", מי שפותח את האפליקציה בגרסה ישנה רואה הודעה שיש עדכון (מגרסה 1.3 עם כפתור "לעדכן" שמעדכן מתוך האפליקציה, וגם התראה בטלפון כשהאפליקציה סגורה),
ומי שלחץ "לעקוב אחרי עדכונים" מקבל התראה בפעמון 🔔 באתר ומייל אחד (מהפונקציה `email`, בריצה של כל שעה, לא בשבת וחג).

## ⚠️ מפתח החתימה
המפתח (`yamshopping-signing-key.p12`) והסיסמה שלו **לא נמצאים בקוד**. שומרים אותם בגיבוי במקום בטוח. בלעדיהם אי אפשר לעדכן את האפליקציה, לא בטלפונים ולא ב-Google Play.
