# רשימת קניות 🛒

אפליקציית רשימות קניות משפחתית בקובץ אחד — יוצרים, מסדרים לפי קטגוריות, ומשתפים בלחיצה.

 yam-shopping.netlify.app **אתר חי**
---

## ✨ מה יש באפליקציה

- 📝 **רשימת קניות בסגנון צ'אט** — מוסיפים פריטים כמו הודעות, עם תמונות לכל פריט
- 🗂️ **לפי קטגוריות** — מוצרי חלב, ירקות, בשר ועוף, ניקיון ועוד — קל לעבור ולראות מה חסר
- 🏠 **"הבית שלי"** — מסמנים מה יש במקרר, והאפליקציה מציעה מה כדאי לקנות
- 👩‍🍳 **יאמי — עוזרת חכמה** — מתכונים לפי מה שיש, תזכורות לפי ימים, ועוזרת לסדר את הרשימה
- 🖨️ **PDF להדפסה** על A4, עם תאריך לועזי ועברי
- 📤 **שיתוף מהיר** — WhatsApp, SMS, מייל גוגל, או העתקת הרשימה
- ☁️ **סנכרון ענן** — קוד אישי לכל משתמש; מי שמקליד את הקוד שלך רואה את הרשימות שלך חיות
- 🌙 מצב כהה, רקע צ'אט עם ציורי אוכל, ולוגו בכתב יד

## 🛠️ איך זה בנוי

- **קובץ HTML אחד** — כל העיצוב והלוגיקה בתוכו, בלי שרת ובלי התקנות
- **Firebase Realtime Database** — סנכרון בזמן אמת בין מחשבים וטלפונים
- **Firebase Authentication** — התחברות עם גוגל (כשהאתר מאוחסן באינטרנט)

## 🚀 איך משתמשים

1. נכנסים לאתר ← מזדהים בשם ואימייל (או גוגל)
2. מוסיפים פריטים, מסדרים לפי קטגוריות, שואלים את יאמי 👩‍🍳
3. כפתור הענן ☁️ יוצר קוד אישי — מתחבר אוטומטית בכל פתיחה
4. חבר שמקליד את הקוד שלך — רואה את הרשימות שלך חיות ומתעדכן תוך שנייה

## 🔒 פרטיות

הנתונים נשמרים במסד פרטי עם הרשאות לפי קוד משתמש. לא נאסף שום מידע מעבר לשם והאימייל שמזינים בה.
